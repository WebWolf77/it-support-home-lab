# 🎫 Ticket 002 - Login Issue

## 👤 User
Mike

## 📌 Issue
User unable to login due to incorrect password  

## 🔍 Diagnosis
- Login attempt failed  
- Incorrect credentials  
- Access denied when using command prompt (no admin rights)  

## 🛠️ Resolution
- Opened Command Prompt as Administrator  
- Reset password using:

```bash
net user labuser 12345
```


## ✅ Result
User successfully logged in  

## 📊 Status
Closed

# 🎫 Ticket 003 - Slow Computer

## 👤 User
Joanna

## 📌 Issue
User reports slow system performance  

## 🔍 Diagnosis
- High CPU usage detected (100%)  
- Multiple applications running  

## 🛠️ Resolution
- Opened Task Manager  
- Identified high CPU processes  
- Terminated unnecessary applications  

## ✅ Result
System performance improved significantly  

## 📊 Status
Closed
