# 🖥️ Active Directory Lab (Windows Server 2022)

## 🎯 Project Overview

This project demonstrates the setup and configuration of an Active Directory Domain Controller in a virtual environment using VirtualBox.

## 🛠️ Technologies Used

* Windows Server 2022
* VirtualBox
* Active Directory Domain Services (AD DS)
* Group Policy Management

## 🔧 Steps Performed

1. Installed Windows Server 2022 on a virtual machine
2. Configured Active Directory Domain Services
3. Promoted server to Domain Controller
4. Created a domain: `company.local`
5. Created Organizational Unit (IT)
6. Created a test user
7. Configured Group Policy:

   * Allowed "Domain Users" to log on locally
8. Applied Group Policy using `gpupdate /force`
9. Tested user login successfully

## 🧪 Result

* Domain controller working
* User authentication successful
* Group Policy applied correctly
