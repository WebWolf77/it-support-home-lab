# 🔐 Password Reset – IT Support Lab

## 🎯 Scenario

User reports: "I cannot log in to my computer due to incorrect password"

---

## 🔍 Steps Taken

### 1. Opened Computer Management

* Pressed `Windows + R`
* Typed `compmgmt.msc`
